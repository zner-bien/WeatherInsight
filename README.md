🌤️ WeatherInsight Features:
1. Search weather information for cities worldwide
2. Real-time temperature and weather conditions
3. Humidity, wind speed, atmospheric pressure, and "feels like" temperature
4. Sunrise and sunset times
5. Live digital clock based on the searched city's local time
6. 5-day weather forecast with a clean and readable layout
7. Recent search history for quick access to previously searched cities
8. Dynamic weather-themed backgrounds with a modern glassmorphism interface

This project was built using Python, Flask, HTML, CSS, JavaScript, and the OpenWeather API. Developing WeatherInsight strengthened my understanding of REST APIs, asynchronous JavaScript (AJAX), Flask routing, responsive UI design, and integrating frontend and backend technologies into a complete web application.
